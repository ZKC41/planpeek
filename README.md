# PlanPeek

**EN** · PlanPeek is a free Android viewer for DWG drawings, PDF, Word, Excel and PowerPoint files, photos and archives.
It needs no account, shows no ads and has no internet permission.
This repository only hosts the installable APK files under **Releases**. It contains no source code.

- Install steps and the SHA-256 of each file: in the notes of each release.

- Download only from the Releases of this repository.
